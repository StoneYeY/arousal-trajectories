# Auditing and Steering Arousal Trajectories in Text-to-Music Generation

Audio companion for the ICASSP 2027 submission. The page is served from `docs/`
via GitHub Pages: https://stoneyey.github.io/arousal-trajectories/

It contains, fully self-contained (all audio embedded):

- six stable-audio-3-medium generations from the audit with their proxy arousal scores,
- two blinded sets from the 24-listener study (jump / rule / rule+BoN), with per-clip listener means revealed on demand,
- one stable-audio-3-medium episode steered by the same objective (prompted / schedule+BoN / jump),
- eight calibration clips comparing the proxy with listener ratings.

DEAM excerpts used in the study are not redistributed.
